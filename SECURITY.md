# Security policy

SFTP Remote Editor reads and writes files on your servers and handles your credentials, so security reports get priority.

## Supported versions

Only the latest version on the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=delta-solutions.sftp-remote-editor) and [Open VSX](https://open-vsx.org/extension/delta-solutions/sftp-remote-editor) receives fixes. VS Code updates extensions automatically, so a fix reaches users quickly.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub's private vulnerability reporting](https://github.com/dietercoopman/sftp-remote-editor/security/advisories/new).

Include the version of the extension, your `sftp.json` with credentials removed, and the steps to reproduce. You get a reply within a few working days. Fixed issues are listed in the [changelog](CHANGELOG.md) and credited if you wish.
